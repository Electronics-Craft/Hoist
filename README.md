# OIST 6-Channel RF Remote Customer Support Website

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `oist-rf-remote-support`.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the website URL.

## Customize

- Replace the wiring placeholder with `images/wiring-diagram.png`.
- Add your product photos to `images/`.
- Replace the tutorial placeholders with YouTube embeds/links.
- Replace `YOUR-EMAIL@example.com`.
- Enter your actual RF frequency, supply voltage, range and output ratings.
- Change `OIST RF CONTROL` to your exact company/brand name.

## Safety

Only publish wiring information that matches your actual receiver PCB and approved electrical design. Include appropriate electrical safety warnings for mains/hoist installations.
